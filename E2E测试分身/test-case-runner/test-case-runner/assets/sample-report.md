### 缺陷详情

#### BUG-001 👁️: 姓名搜索无结果时表格未清空（内容不一致）

- **关联用例**: TC-PED-011 (姓名搜索无结果)
- **功能点**: FP-006 (姓名搜索)
- **失败类型**: 内容不一致 — MCP 操作全部成功执行，但截图内容与预期结果不符
- **严重程度**: 中
- **现象**: 输入不存在的姓名"zzzzzz不存在"后点击查询，表格未清空也未显示"暂无数据"提示，仍显示之前查询的数据
- **预期**: 表格应显示空数据或"暂无数据"提示，数据总条数显示为 0
- **实际**: 表格保持上一次查询结果不变
- **可能原因**:
  1. 前端未正确处理后端返回的空数据集
  2. iframe 上下文中表格数据更新逻辑异常
- **复现步骤**: 先搜索"朱彬"(有结果) → 再搜索"zzzzzz不存在"(无结果) → 观察表格未变化
- **截图证据**: TC-PED-011_name_no_result.png

#### BUG-002 👁️: 时间范围为空时校验缺失（内容不一致）

- **关联用例**: TC-PED-007 (时间范围为空)
- **功能点**: FP-004 (时间范围筛选)
- **失败类型**: 内容不一致 — MCP 操作全部成功执行，但截图内容与预期结果不符
- **严重程度**: 中
- **现象**: 清空开始时间后点击查询，未弹出校验提示"请选择时间范围"，表格直接刷新显示全量数据
- **预期**: 清空时间范围后点击查询，应弹出校验提示，表格不刷新
- **实际**: 无校验提示弹窗，表格直接刷新
- **可能原因**: 前端校验逻辑缺失
- **截图证据**: TC-PED-007_time_range_empty.png

#### BUG-003 🔧: 导出表格按钮 uid 定位失败（执行失败）

- **关联用例**: TC-PED-013 (导出表格)
- **功能点**: FP-008 (导出表格)

- **严重程度**: 高
