# 第四步：热点素材深度整理

在动笔之前，必须给该热点做一轮"横纵整理"，确保文章**有理有据**。

## 4.1 纵向脉络（事件是怎么来的）

用 WebSearch 搜索该热点的**起源和发展时间线**：
- 事件第一次出现是什么时候？在哪里？
- 关键转折点有哪些？（谁说了什么、做了什么、官方/当事人如何回应）
- 事件目前进展到什么阶段？

```
【纵向脉络】
- 起源：...
- 关键节点1（时间）：...
- 关键节点2（时间）：...
- 当前状态：...
```

## 4.2 横向切片（各方怎么看）

搜索该热点的**多方观点和关键数据**：
- 官方/当事人怎么说？（原话或核心态度）
- 网友/舆论的主要分歧点在哪？
- 有没有相关数据支撑？（数字、比例、金额、排名等）
- 类似的历史案例或对比对象？

```
【横向切片】
- 官方/当事人态度：...
- 舆论分歧点：...
- 关键数据：...
- 类似案例/对比：...
```

## 4.3 提炼文章骨架

基于以上调研，提炼出 2-3 个**有事实支撑的核心观点**：

```
【文章骨架】
观点1：...
→ 支撑：...

观点2：...
→ 支撑：...

金句预埋：...
```

## 注意事项

- 搜索时至少查 3-5 个不同来源，交叉验证关键事实
- 搜不到的信息诚实标注"信息暂缺"，绝不编造
