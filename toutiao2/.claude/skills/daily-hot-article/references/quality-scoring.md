# 文章质量多维度评分体系

> 用于评估已生成的头条文章质量，反馈优化写作 skill。
> 满分 100 分，60 分以下为不合格。

## 评分标准

### 1. 标题锋芒度（15分）

| 分数 | 标准 |
|------|------|
| 13-15 | 标题≤28字 + 冲突/反常识 + 具体数字/人物 + 让人立即想点 |
| 9-12 | 标题≤28字 + 有观点但不够锐利，或有数字但缺冲突 |
| 5-8 | 标题合规但平庸，像新闻标题而非观点文 |
| 0-4 | 超28字 / 纯信息传递 / 无锋芒 |

**好标题示例**：
- ✅ 双汇十年分红517亿，猪肉变成了境外提款机（数字+冲突+锐利判断）
- ✅ 康师傅冰红茶涨价5毛，丢掉了7亿（小因大果，数字反差）
- ✅ 花30万闪婚22天新娘消失，娶妻流水线有多黑（荒诞事实+质问）

**差标题示例**：
- ❌ 村民在线求助缺收割机，半天全收完了（温暖但无锋芒）
- ❌ 2026高考来了，教育部提醒别被骗（信息型，无冲突）
- ❌ NBA总决赛G1收视近2000万，尼克斯回来了（数据陈述）

### 2. 开头钩子力（12分）

| 分数 | 标准 |
|------|------|
| 10-12 | 首句即冲突/荒诞事实，3句内让人必须往下看 |
| 7-9 | 具体事件切入，前3句有吸引力但不够炸 |
| 4-6 | 铺垫式开头，需要4-5句才进入主题 |
| 0-3 | 宏大叙事 / 教科书式开头 / 背景交代 |

### 3. 观点密度与金句（18分）

| 分数 | 标准 |
|------|------|
| 15-18 | 2-3个锐利观点 + 金句像刀子 + 每200字一个记忆点 |
| 11-14 | 2-3个观点但部分金句偏温吞，或观点有重复 |
| 7-10 | 1-2个观点，金句像漂亮话而非锐利洞察 |
| 0-6 | 观点散乱/缺失，金句像鸡汤 |

### 4. 论据支撑（15分）

| 分数 | 标准 |
|------|------|
| 13-15 | 每个观点有具体数字/人名/事件/引语，可验证可追溯 |
| 9-12 | 大部分观点有支撑，个别论据偏模糊 |
| 5-8 | 有论据但稀疏，部分观点只有论断没有例证 |
| 0-4 | 大量空泛观点，「很多网友说」式论证 |

### 5. 口语化与活人感（12分）

| 分数 | 标准 |
|------|------|
| 10-12 | ≥8个口语词组 + 论述中故意打破 + 有情绪标点 + 有自嘲 |
| 7-9 | 5-7个口语词组，有口语感但不稳定，偶有书面语滑落 |
| 4-6 | 3-5个口语词组，整体像观点文而非聊天 |
| 0-3 | 全文书面语，无口语词组，像AI输出 |

### 6. 节奏与结构（8分）

| 分数 | 标准 |
|------|------|
| 7-8 | 长短句交替流畅 + 断裂句≥3处 + 回环呼应到位 |
| 5-6 | 节奏基本OK，偶有拖沓段，断裂句1-2处 |
| 3-4 | 句式单调，连续3句以上句式相近 |
| 0-2 | 无节奏设计，像报告 |

### 7. 硬性合规（10分）

| 项目 | 扣分规则 |
|------|----------|
| 禁用词命中 | 每处 -2 |
| 禁用标点命中 | 每处 -1 |
| 缺少情绪标点 | -2 |
| 缺少评论引导 | -3 |
| 字数<700字 | -3 |
| 字数>1000字 | -2 |

基础分10分，扣完为止。

### 8. 情绪收束与洞察（10分）

| 分数 | 标准 |
|------|------|
| 8-10 | 冷峻洞察或行动质问 + callback开头 + 留思考空间 |
| 5-7 | 有收束但偏温和，或callback不够巧妙 |
| 3-4 | 收束仓促，像硬加的尾巴 |
| 0-2 | 无收束感，文章突然结束 |

### 9. 结构多样性（8分，v2.0 新增）

| 分数 | 标准 |
|------|------|
| 7-8 | 明确使用了5种结构变体之一 + 结构与话题高度匹配 + 与同批次文章不重复 |
| 5-6 | 使用了某种结构但与话题匹配度一般，或与同批次重复 |
| 3-4 | 结构模糊，看不出明确的模板选择 |
| 0-2 | 完全同质化结构（开头→观点→加粗→总结→CTA），与 v1.0 无区别 |

### 10. 可操作性（7分，v2.0 新增）

| 分数 | 标准 |
|------|------|
| 6-7 | 包含具体可操作步骤/清单/数据对比，读者看完能"学到了"并行动 |
| 4-5 | 有部分实用信息但不够具体，或信息块与正文脱节 |
| 2-3 | 仅有泛泛建议（"建议大家关注"），无可操作性 |
| 0-1 | 纯观点输出，读完只有"说得对"没有"学到了" |

**说明**：不是所有话题都需要高可操作性。人物故事、体育赛事类话题此维度权重可降低（×0.7）。民生政策、生活指南类话题此维度权重提高（×1.3）。

## 质量等级

| 等级 | 分数区间 | 含义 |
|------|----------|------|
| S | 90-100 | 标杆级，可作为范文 |
| A | 80-89 | 高质量，可直接发布 |
| B | 70-79 | 中质量，需小幅修改 |
| C | 60-69 | 低质量，需大幅修改 |
| D | <60 | 不合格，需重写 |

## 话题类型权重修正

不同话题类型，各维度的重要性不同：

| 话题类型 | 加强维度 | 减弱维度 | 说明 |
|----------|----------|----------|------|
| **财经揭秘** | 论据支撑×1.3, 观点密度×1.2 | 情绪收束×0.8 | 数据是命脉，洞察比情绪重要 |
| **社会矛盾** | 标题锋芒×1.2, 情绪收束×1.2 | 口语化×0.9 | 标题要刺人，结尾要留痛 |
| **民生政策** | 口语化×1.2, 论据支撑×1.1 | 标题锋芒×0.9 | 把政策翻译成人话是核心能力 |
| **科技争议** | 观点密度×1.2, 论据支撑×1.1 | 情绪收束×0.9 | 需要锐利判断+事实，而非情绪 |
| **人物故事** | 情绪收束×1.2, 口语化×1.1 | 论据支撑×0.9 | 共情力>数据密度 |
| **娱乐八卦** | 标题锋芒×1.2, 口语化×1.2 | 论据支撑×0.7 | 趣味和态度比深度重要 |
| **体育赛事** | 标题锋芒×1.3, 观点密度×1.2 | 论据支撑×0.8 | 必须有超越比分的洞察 |
| **国际时政** | 观点密度×1.2, 节奏结构×1.2 | 口语化×0.9 | 战略分析要有层次感 |

## 改进建议（按优先级排序）

### P0 — 必须在 skill 中强化

1. **情绪标点强制检查**：在 L1 自检中增加「情绪标点≥1处」硬检，缺少则必须补
2. **禁用词扫描增强**：「意味着什么」「这意味着」「本质上」三词命中率最高，需加入写作阶段的实时提醒
3. **字数下限提升**：从「约800字」改为「≥780字，目标850字」

### P1 — 写作阶段优化

4. **标题生成规则**：增加「标题必须包含冲突词或反差数字」的硬规则
5. **金句质检**：增加「金句是否能在3秒内让人停下来」的自检项
6. **话题类型适配**：根据话题类型自动调整各维度权重，避免对暖心/正能量类话题强求冲突

### P2 — 选话题段优化

7. **话题类型淘汰**：在 Top 5 选话题时，自动降权「纯暖心」「纯正能量」「纯体育比分」类话题
8. **口语化词组计数**：写作完成后强制统计口语词组数量，<5个则返工

### P3 — v2.0 新增评分维度

9. **结构多样性（8分）**：强制使用5种结构变体之一（A-E），同批次不重复。当前30篇全部同质化结构，预期提升空间最大
10. **可操作性（7分）**：民生政策/生活指南类话题必须包含可操作信息块（步骤/数据对比/避坑提醒）。当前多数文章读完只有"说得对"没有"学到了"

## 使用指南

### 单篇评分

逐维度打分，乘以话题类型权重修正系数，计算加权总分。

### 批量评估（≥10 篇）

除总分外还应统计：
- 各维度平均得分率（找出最弱维度）
- 标准差（找出波动最大维度）
- 结构变体分布（A/B/C/D/E 各占多少？集中度过高则扣分）
- 可操作信息块覆盖率（民生/政策类是否 100% 包含？）

### v1.0 → v2.0 对比

对比时关注原 8 维度得分率变化 + 新维度得分率：
- 原 8 维度：v2.0 得分率应 ≥ v1.0（结构变化不应导致原维度退步）
- 新 2 维度：v2.0 目标得分率 ≥ 75%（结构多样性）、≥ 70%（可操作性）
