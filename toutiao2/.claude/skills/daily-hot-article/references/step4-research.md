# 第四步：热点素材深度整理

在动笔之前，必须给该热点做一轮"横纵整理"，确保文章**有理有据**。

## 4.1 纵向脉络（事件是怎么来的）

用 WebSearch 搜索该热点的**起源和发展时间线**：
- 事件第一次出现是什么时候？在哪里？
- 关键转折点有哪些？（谁说了什么、做了什么、官方/当事人如何回应）
- 事件目前进展到什么阶段？

```
【纵向脉络】
- 起源：...
- 关键节点1（时间）：...
- 关键节点2（时间）：...
- 当前状态：...
```

## 4.2 横向切片（各方怎么看）

搜索该热点的**多方观点和关键数据**：
- 官方/当事人怎么说？（原话或核心态度）
- 网友/舆论的主要分歧点在哪？
- 有没有相关数据支撑？（数字、比例、金额、排名等）
- 类似的历史案例或对比对象？

```
【横向切片】
- 官方/当事人态度：...
- 舆论分歧点：...
- 关键数据：...
- 类似案例/对比：...
```

## 4.3 提炼文章骨架

基于以上调研，提炼出 2-3 个**有事实支撑的核心观点**：

```
【文章骨架】
观点1：...
→ 支撑：...

观点2：...
→ 支撑：...

【v2.0 增量数据点】：...
【v2.0 原始信源】：...
金句预埋：...
```

## v2.0 强制增量要求

**每篇文章的素材调研必须包含以下两项，否则不允许进入写作阶段**：

### 增量数据点（≥1 个）

必须找到至少 1 个**热搜标题本身没有提供的具体数据**。例如：
- 热搜标题说「退休金差一倍」→ 增量数据：具体差多少？北京 vs 河南？差距从哪一年开始扩大？
- 热搜标题说「涨价5毛」→ 增量数据：涨了多少次？累计涨幅？竞品同期价格变化？
- 热搜标题说「13分钟」→ 增量数据：国家标准急诊响应时间是多少？其他国家急诊等待时间？

### 原始信源（≥1 个）

必须找到至少 1 个**原始信源**，而非二手转述。例如：
- 当事人原话（微博原文、采访原话、官方通报原文）
- 法律条文原文（哪部法律第几条）
- 政府文件原文（政策文件编号、发布日期）
- 学术论文/统计报告（具体数据来源）

**搜不到时的处理**：诚实标注「增量数据暂缺」或「原始信源暂缺」，并在文章中说明信息来源的局限性。绝不编造。

## 注意事项

- 搜索时至少查 3-5 个不同来源，交叉验证关键事实
- 搜不到的信息诚实标注"信息暂缺"，绝不编造
