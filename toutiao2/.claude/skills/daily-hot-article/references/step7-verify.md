# 第七步：验证配图完整性

文章写好后，**必须**运行图片验证脚本，确保 md 中所有 `![...](URL)` 引用的图片都能正常访问：

```bash
python ./scripts/verify_md_images.py "<话题关键词>_头条文章.md"
```

## 验证逻辑

- 提取 md 文件中所有 `![描述](URL)` 图片引用
- 对每个 URL 发送 HEAD 请求（超时 10 秒），检查是否返回 200
- 若 HEAD 请求失败，降级发送 GET 请求检查 Content-Type 是否为图片类型
- 输出验证报告：总图片数、有效数、失效数及失效 URL 列表

## 处理失效图片

- 如果有图片验证失败，用 `image_search.py` 重新搜索替换失效图片
- 替换后**再次运行验证**，直到所有图片全部通过
- 如果某个关键词实在搜不到可用图片，删除该图片引用（不留死链），确保最终 md 中**零失效图片**
