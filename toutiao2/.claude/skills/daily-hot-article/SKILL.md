# 今日热点 → 头条文章

一站式流程：搜集热点 → 提炼 Top 5 → 用户确认 → 素材调研 → 文章写作 → 配图搜索 → 图片验证 → 导出 md。

## 前置依赖

- **newsnow CLI**（需全局安装）：`npm install -g newsnow`
- **Python 依赖**：`pip install requests`
- **tianapi-toutiao skill**（**必需**）：用于获取头条热搜榜热度指数，详见 `../tianapi-toutiao/SKILL.md`

## 工作流程

按顺序执行以下 8 步，执行每一步时**先读取对应的详情文件**获取完整指令：

| 步骤 | 内容 | 详情文件 |
|------|------|----------|
| 1 | **搜集热点** — 运行 `python ./scripts/fetch_and_analyze.py` | `references/step1-fetch.md` |
| 2 | **提炼 Top 5** — AI 二次审视 + 五维点击吸引力评分 | `references/step2-top5.md` |
| 3 | **用户确认选题** — 等待用户选择，不要自动选 | `references/step3-confirm.md` |
| 4 | **素材深度调研** — 纵向脉络 + 横向切片 + 文章骨架 | `references/step4-research.md` |
| 5 | **生成头条文章** — 犀利尖锐风格，目标 800 字，上限 850 字 | `references/step5-writing.md` |
| 6 | **配图搜索** — 为文章搜索 1-3 张相关配图 | `references/step6-images.md` |
| 7 | **图片验证** — 运行 `python ./scripts/verify_md_images.py` 验证图片可访问 | `references/step7-verify.md` |
| 8 | **输出结果** — 文件路径 + 文章概要 | `references/step8-output.md` |

> 📊 **质量评分**：生成后使用 `references/quality-scoring.md` 进行多维度评估。

## 写作规范

文章写作严格执行 `./khazix-writer/SKILL.md` 中的全部规范（四阶段工作流、禁用词列表、风格要求等）。

## 质量评分权重（写前必读）

> 完整评分体系详见 `references/quality-scoring.md`

文章质量按 10 维度加权评分，**写作时按权重分配精力**：

| 维度 | 权重 | 写作要求 |
|------|------|----------|
| **标题锋芒度** | 13% | ≤28字 + 冲突/反差 + 数字钩子 |
| **开头钩子力** | 10% | 前3句勾住人，具体事件切入 |
| **观点密度与金句** | 15% | 2-3个锐利观点，金句像刀子而非鸡汤 |
| **论据支撑** | 13% | 每个观点有具体数字/人名/事件，禁止「很多网友说」 |
| **口语化与活人感** | 10% | ≥8个口语词组 + 情绪标点(。。。？？？) + 论述中故意打破 |
| **节奏与结构** | 7% | 长短句交替 + 一句话独立成段≥3次 + 回环呼应 |
| **硬性合规** | 8% | 禁用词0命中 + 禁用标点0命中 + 评论引导句 |
| **情绪收束与洞察** | 9% | 冷峻收尾 + callback开头 + 留思考空间 |
| **结构多样性（v2.0）** | 8% | 使用5种结构变体之一(A-E) + 与同批次不重复 |
| **可操作性（v2.0）** | 7% | 包含可操作步骤/清单/数据对比，读完能"学到了" |

## 输出约束

- **标题不超过28字**（含标点），必须有锋芒
- **只输出 .md**，不生成 HTML、PDF 或 Docx
- 文章风格：**犀利、尖锐、发人深思**
- **≥780字，目标800字，上限850字**（v2.0 硬约束，超过必须删减）
- 每个核心观点必须有事实/数据支撑
- **必须插入 1-3 张配图**（v2.0 新增，通过 step6-7 完成）
- **必须使用5种结构变体之一**（A/B/C/D/E，详见 step5-writing.md）
- **v2.0 强制增量**：素材调研必须包含 ≥1 个增量数据点 + ≥1 个原始信源

## 注意事项

- newsnow 某源拉取失败时跳过该源继续，不影响整体
- Top 5 核心标准是"点击吸引力"而非"纯热度"——有刺痛感、有争议、有信息差优先
- 素材调研至少查 3-5 个来源，交叉验证关键事实
- 用户可以不选 Top 5，自己指定任意热点话题
- 头条热度指数获取为强制步骤，由 tianapi-toutiao skill 自动完成
